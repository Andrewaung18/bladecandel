# Bladecandel — Artist Intake Form

Intake form prepared by Openhour Studio to collect Bladecandel's biography, highlights, photo link, socials, booking details and website wishes.

Submissions are sent through [Web3Forms](https://web3forms.com) to Openhour Studio's inbox. After a successful send the artist sees a thank-you screen; if sending fails, the answers stay on the form so they can press Send again. Answers also save in the browser as a draft while typing.

Photos are shared as a link (WeTransfer, Google Drive or iCloud), since the free Web3Forms plan doesn't accept file uploads.
